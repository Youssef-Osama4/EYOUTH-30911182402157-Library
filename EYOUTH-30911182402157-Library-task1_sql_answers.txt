Question 1: How much is each member borrowing?

Code:
query='''
SELECT members.member_id, members.first_name, members.last_name, COUNT(checkouts.member_id) AS checkout_count
FROM members
LEFT JOIN checkouts
ON checkouts.member_id = members.member_id
GROUP BY members.member_id
'''
print(pd.read_sql_query(query, conn))

Explanation:
I selected the member id and his full name and the checkout count to be shown.
I joined members and checkouts to show the member's data while showing his checkouts count, using the primary key "members.member_id" and the foreign key "checkouts.member_id".
I used "LEFT JOIN" method to make sure all members are shown (including those with no checkouts).
I used GROUP BY member id to group all checkouts which belong to the same member so they can be counted.

Question 3: What are the most popular books?

Code:
query = '''
SELECT books.book_id, books.title, COUNT(*) AS borrows_count
FROM checkouts
JOIN books
ON checkouts.book_id = books.book_id
GROUP BY checkouts.book_id
ORDER BY COUNT(*) DESC
LIMIT 5
'''
print(pd.read_sql_query(query, conn))

Explanation:
I selected the book id and its title and how much it was borrowed to be shown.
I joined checkouts and books to show the book data while showing its borrows count, using the primary key "books.book_id" and the foreign key "checkouts.book_id".
I used GROUP BY book id to group all checkouts which belong to the same book so they can be counted.
I used ORDER BY DESC to sort the books from the most borrowed to the least.
I used LIMIT 5 to show only the first 5 most borrowed books.

Question 5: What does a neighborhood's activity look like further back in time?

Code:
query = '''
SELECT checkouts.checkout_id, members.first_name, checkouts.checkout_date, members.neighborhood
FROM checkouts
JOIN members
ON checkouts.member_id = members.member_id
WHERE members.neighborhood = 'Maadi'
ORDER BY checkouts.checkout_date DESC
LIMIT 10
OFFSET 10
'''
print(pd.read_sql_query(query, conn)) #What does a neighborhood's (Maadi) activity look like further back in time?

Explanation:
I chose the neighborhood (Maadi)
I selected the checkout id and and the member's first name and the checkout_date and the member's neighborhood to be shown.
I joined checkouts and members to show the checkout data while showing the member's data, using the primary key "members.member_id" and the foreign key "checkouts.member_id".
I used WHERE method to make a rule that the member's neighborhood should be Maadi.
I used ORDER BY DESC to sort the checkouts from the most recent to the least.
I used LIMIT 10 to show only the first 10 most recent checkouts.
I used OFFSET 10 to skip the most 10 recent checkouts (Which means I will show the next 10 checkouts).

Web Page vs API

A web page is made for people to read using a browser, while an API is made for programs to access data directly in a more 'official' way, and a database is also read easily using programs (like sql). In this project, the Reading Kickoff data was on a web page, so I had to extract all the tables from the HTML using Pandas (in the reading Kickoff it was only one table), then selecting the table which I want to use.
